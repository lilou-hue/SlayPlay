Music

Dread Low, Night Wall and Pursuit were rendered with MuseScore Studio 4.7.6 using the MS Basic soundfont (MuseScore_General). Its credits include Frank Wen (FluidR3), Michael Cowgill (FluidR3Mono), S. Christian Collins (MuseScore_General), Ethan Winer (Temple Blocks) and Michael Schorsch (Drumline Cymbals).

The complete MS Basic acknowledgements and MIT licence are included with this game. Other score cues are synthesised for the game.

Community features and local saves

Story saves and settings stay in this browser's local storage; they do not sync between devices. Clearing site data can remove them. The story does not need a community account.

The wall-child gallery and end-of-game reviews connect to https://trailblazermerch.lol/api/dkb. The gallery is public: hanging a wall child sends the names and rule you enter and its selected parts and positions, and anyone who opens the gallery can see them. A review sends the stars, name and optional message you enter. The name and message are feedback for the game's author and are not published; only the rating average and the number of reviews are public. Do not include private or sensitive information.

This describes what the game client does. It is not a complete server privacy policy: retention, server logs and a contact for data requests still need to be documented.

Fonts and printable pages

The game uses system font stacks. The QR sign and posters request Fraunces and Inter from Google Fonts when opened; those font files are not bundled with the game.
